# Project112 — актуальный сценарий разработки

Дата актуализации: 2026-11-03  
Цель: рабочий демонстратор трёх нативных видеорежимов ATM Turbo 2+ v7.10 в UnrealSpeccy.

## 1. Целевая конфигурация

- Эмулятор: UnrealSpeccy, модель `ATM710`.
- ОЗУ: 1024 КБ.
- `AtmMemSwap=1`.
- `EFF7mask=0`.
- `UsePalette=1`.
- ROMSET: `ATM2`.
- Конфигурация находится в корневом `unreal.ini`.

## 2. Активная последовательность режимов

Переключение клавишей Space, после отпускания клавиши:

| Индекс | RG2..RG0 | Режим | Назначение |
|---:|---:|---|---|
| 0 | 3 | Sinclair 256×192 | исходный режим и возврат |
| 1 | 2 | ATM 640×200 | аппаратный мультиколор |
| 2 | 0 | ATM EGA 320×200 | 16 цветов |
| 3 | 6 | ATM Text 80×25 | аппаратный текст |

Фактический цикл текущего кода: Sinclair → ATM 640 → EGA → Text → Sinclair. Таким образом, первый переход по Space — именно Sinclair → ATM 640. Возврат в Sinclair отдельно восстанавливает стандартную карту памяти и системный регистр.

## 3. Загрузочная цепочка

1. SjASMPlus собирает `112/src/main.asm`.
2. В TRD создаётся BASIC-файл `boot.B`.
3. BASIC выполняет инициализацию TR-DOS через `RANDOMIZE USR 15619`.
4. Загружается `proj112.C` по адресу `$8000`.
5. Диагностическая строка BASIC отмечает завершение загрузки.
6. BASIC передаёт управление на `$8000`.
7. Машинный код выводит символ входа `Z` в диагностический порт `#EF`.
8. До любого прямого обращения к теневым портам выполняется TR-DOS ROM trampoline: стек подготавливается адресами возврата `OpenATMShadowPortsDone112` и `#2A53`, затем выполняется `JP #3D2F` с `BC=#0177`, `A=$C3`. ПЗУ выполняет `OUT (C),A`; CPM/A9=0 открывает теневые порты.
9. Только после открытия теневых портов выбирается стандартная страница ZX-128 через `OUT (#7FFD),0`.
10. Выполняется `DrawDemoScreen`, затем основной цикл ожидает Space.

Структура каждой BASIC-строки: номер (старший байт первым), длина тела (младший байт первым), токенизированное тело и CR. После последней строки программы обязателен байт `$80`. Он включается в размер сохраняемого `boot.B`.

## 4. Карта памяти и видеопамять

Диспетчер ATM программируется теневым портом `#7FF7` для окна `$4000-$7FFF` и `#FFF7` для окна `$C000-$FFFF`.

- Физическая RAM page 5 отображается в окно `$4000-$7FFF`: данные `$7A` (инверсия номера страницы 5, RAM, D7=0).
- Физическая RAM page 1 отображается в окно `$C000-$FFFF`: данные `$7E` (инверсия номера страницы 1, RAM, D7=0).
- Программа загружается в окно `$8000-$BFFF`; стек устанавливается на `$BFFF`, поэтому очистка экранных окон не затирает стек.
- Системный порт ATM: `#FF77` (теневой). Нельзя считать прямую запись в него доступной до открытия DOSEN.
- Для открытия используется `#0177` и значение `$C3` через TR-DOS ROM trampoline; это устанавливает RG=3 (Sinclair), VE1=1, VE0=1 и CPM/A9=0.
- После открытия теневых портов доступ к `#7FF7` и `#FFF7` сохраняется, пока CPM/A9 не сброшен обратно.
- Повторный вызов `#3D2F` при переключении режимов не нужен и опасен: после изменения `#7FFD` ROM по этому адресу может быть уже не TR-DOS.
- Возврат в Sinclair восстанавливает окно 1 на RAM page 5, окно 3 на RAM page 0, затем `#7FFD=0` и RG=3.

### ATM 640×200

- 40 байтов на растровую строку в каждой половине.
- Чётные и нечётные знакоместа разделены по областям `$4000` и `$6000` (bitmap), `$C000` и `$E000` (атрибуты).
- Смещение: `(row*8 + glyph_line)*40 + column/2`.

### ATM EGA 320×200×16

- Четыре видеоплоскости: `$C000`, `$4000`, `$E000`, `$6000`.
- На каждую растровую строку приходится 40 байтов в каждой плоскости.
- Каждый символ формирует четыре двухпиксельные пары — по одной на плоскость.

### ATM Text 80×25

- Коды символов: page 5, базовые области `$4000`/`$6000`.
- Атрибуты: page 1; чётный столбец — `$E000 + offset`, нечётный — `$C000 + offset + 1` (дополнительный байт `BIT(x,3)` по видеодекодеру ATM2+).
- Смещение знакоместа: `$01C0 + row*64 + column/2`.

## 9. Исправление после пользовательского теста 2026-11-03

Пользователь подтвердил: Sinclair и ATM640 работают; EGA показывает пиксельный мусор; ATM Text рисует мелкие пиксели; возврат в Sinclair не восстанавливает экран.

Причина в адресе системного регистра ATM. Код записывал RG через адрес #FF77. Для ATM2+ бит A9 адреса порта определяет CPM/DOSEN: при #FF77 A9=1, теневые F7-порты отключаются. Поэтому последующие переключения страниц #7FF7/#FFF7 уже не выполняются, что объясняет неверную видеопамять EGA/Text и неработающий возврат в Sinclair.

Исправление: все записи RG выполняются через #0177 (A9=0, PEN=1); в динамическом trampoline байты адреса изменены с #FF77 на #0177. В ATM Text дополнительно исправлен адрес атрибута нечётного столбца: #C000 + offset + 1 согласно BIT(x,3) в видеодекодере ATM2+.

EGA-раскладка четырёх областей оставлена без изменения: порядок #C000, #4000, #E000, #6000 соответствует четырём сочетаниям битов X1/X2 декодера ATM2+. Синтаксическая/эмуляторная проверка ещё не выполнена.
